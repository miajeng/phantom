# One boulder per line, made in this order and numbered 1, 2, ...:
#   x y z    centre in km, relative to the body's centre of mass
#   a b c    semi-axes in km (a = b = c for a sphere)
#   rx ry rz optional rotations in degrees, about x, then y, then z
